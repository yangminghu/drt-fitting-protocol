## 1. 输入数据规范

1. 接受格式：纯文本，每行三列 `f / Hz`, `Z' / Ω`, `Z''(=Im Z) / Ω`，空白或逗号分隔；三列之外的多余列忽略，无法解析的行跳过并计数报告。
2. 符号约定：**`Z'' > 0` 表示感性**。数据在最高频 `Z'' > 0`、中低频为负 → 约定正确。整段符号相反时必须先取得**定量证据**再取反，不得凭感觉：
   - 写明第三列在**源文件里的列头**（`Zimag` 还是 `-Z''`）与最高频点的相位符号；
   - 做一次**反号对照拟合**（同模型、同网格），记录 `R`、`max|Δ_Re|`、`max|Δ_Im|`、`rms`；
   - 反号解明显不可拟合（残差 ≫ 1 % 或 `R` 无物理意义）→ "按原样解释"已获定量支持，不必再问用户；两者都能拟合才必须回用户确认。
3. **必须按 UTF-8 BOM 容错读取**（`encoding="utf-8-sig"`）。BOM 会让普通解析器丢掉**第一行**，而第一行通常正是最高频点（如 1 MHz）：高频残差会从 0.5 % 恶化到 9 %，残差图纵轴随之缩小、看起来"正常"，是排查此类问题的第一线索。
4. 读入后立刻校验并打印：点数 `n`、频率范围与十倍频跨度、**`Zmin = min Z'`**（H4 要用）、`Z''` 在 `f_max` 处的符号、频率是否单调递减、有无重复点。
5. **输入完整性**：同目录若存在**信息更全的同名源文件**（`.xlsx` / `.nox`），必须逐点交叉核对给定 txt 是否为源文件的**前 n 点且逐点一致**。若点数更少 → 判为"提前截断"，必须从源文件恢复缺失频段（使组内窗口一致而不丢谷点）并在报告中列出（给定点数 / 源点数 / 真前缀校验结论）。仪器 xlsx 列头常写 `-Z''`，须先统一符号再比对。
   **文件名后缀（`trimmed` / `去尾` 之类）不构成任何处理证据** —— 实测曾出现多数带「去尾」后缀的文件其实完全没去尾（点数与原始文件一样多）。
   > md5 只对**文本 vs 文本**有效：源文件是二进制时 `md5(xlsx) ≠ md5(txt)` 恒成立，该判据结构性空转，改用"点数减少 + 逐点前缀"作证据。
6. **工程陷阱**：`openpyxl` 以 `read_only=True` 读缺 `dimension` 元数据的 xlsx 会**静默读出 0 行** —— 读入后校验行数，为 0 就换非只读方式。中文路径**不要**经 shell 字符串传递（会乱码），写进 `.py` 或参数文件；控制台统一 `PYTHONIOENCODING=utf-8` 或 `sys.stdout.reconfigure(encoding="utf-8")`。
7. **【硬门槛 H7′】`Z'` 单调性前置体检**。`γ ≥ 0` 时模型实部 `Z' = R + Σ_k γ_k Δlnτ_k /(1+(ωτ_k)²)` 对 ω 单调，因此在"高频→低频"文件序下（若文件是升频序，先反转再判）`Z'[i+1] − Z'[i]` **不得为负**。
   - **判定方式是"披露门槛"，不是"结果门槛"**：把全部 `ΔZ'[i] < 0` 的点逐点列出（频率 + `ΔZ'`；一个都没有就写"无"），并指出 `|ΔZ'|` 最大的那个点是否就是 `max|Δ_Re|` 所在点。**披露齐备即 PASS**；未做体检、或把残差超限归因于"λ/网格/模型"而未提这些点，判 **FAIL**。
   - 显著性：只有 `|ΔZ'| ≥ 1e-3 Ω` 的点计为『非单调点』（量级上高于仪器噪声与 `%.6g` 级舍入），更小的抖动记入附件但不作归因依据；**判定用的始终是 `ΔZ' < 0` 本身**。
   - **两种情形必须分开处置**：
     - **顶 1–2 个孤立点**（其余频段 `Z'` 单调）→ 按 H7 的**剔点补救**，上限就是顶 1–2 点，**不得**逐步扩大；
     - **连续 ≥ 3 个点**（`Z'` 在最高一段持续下降，说明**整段高频被夹具/线缆谐振污染**）→ **不属于『剔点』**：必须把**窗口上限整段下移到最后一个非单调点之上**，报告里写明是『**整段排除**』而不是『剔点』，并判 **H10 警告** + 建议短路参考测量；若整段排除后仍不达标，判 H7 FAIL。
       > 实测（双弧批次）：连续 8 个非单调点的两个样品，剔顶 2 点残差仍 10–11 %，剔顶 8 点才降到 0.35 %/0.55 % —— 污染是**整段**的，『剔 1–2 点』这条上限在这种数据上不适用。
   - 含义：`Z'` 下降说明该点含**夹具/线缆杂散**（单个串联 `L` 只影响 `Z''`，不会让 `Z'` 下降）。这类点**任何 `γ ≥ 0` 的模型都表示不了**，残差必然在该点冒尖 —— 先做这一步，就不会为了 1–2 个坏点反复调 λ 与网格。

## 2. 预处理：去除低频扩散尾

**判据**：从高频往低频扫描，找 `Z''` 的**局部极大值**（最后一个半圆与扩散尾之间的"谷"），**保留该点，删除它以下（更低频）的所有点**；搜索范围限制在 `f < 1e5 Hz`。若整段 `Z''` 单调、找不到局部极大值，说明扩散尾未测全，**不要截断**并说明。截断后必须在报告里写出**截断频率**。

- **R1 判据**：局部极大值 = `Z''[i] > Z''[i−1]` 且 `Z''[i] ≥ Z''[i+1]`，且 `f[i] < 1e5 Hz`。
- **R2′ 取"尾段起点"**：记 `Tail = { i : 对全部 j ≥ i 有 Z''[j+1] ≤ Z''[j] }`（"从此点起直到 `f_min` 一路**单调加深**"的点集），取 `i* = min(Tail)`，截断点 = `f[i*]`（保留 `f[i*]` 及其以上全部点）。
  - `Tail` **恒非空**（至少含最后一个点），故 R2′ **总有解、不需要备用规则、也不会不终止**；在"弧 + 干净扩散尾"的常见情形下 `i*` 恰是最后一个 `Z''` 局部极大值。
  - 扩散尾有噪声抖动时，"单调加深"的起点会自动**下移到抖动之后**（截得更少、保留更多尾段），这是保守方向，因此**不设人为抖动容差**。
- **R3 保谷点、删更低频**：保留 `i*` 本身，删除它以下所有点；`i*` 之后仍有大量单调加深的点说明扩散尾很长，照删。
- **多弧数据**：R2′ 取的是**最后一个谷**，所以窗口内**保留全部弧**（弧 1、弧 2 … 都在 `i*` 以上）。只有"取最靠高频的谷"那种做法才会把第二个弧整段删掉 —— H1′ 就是为它设的。

```python
def find_valley(f, zi, fmax_search=1e5):
    """R2′：返回截断点索引 i*（保留 0..i* 的点），使 f[i*] 以下 Z'' 单调不增（= 真扩散尾）。
    干净尾段上等价于"最后一个 Z'' 局部极大值"（即最后一个谷）。

    §2 判据：若在 f < fmax_search 内**找不到 Z'' 的局部极大值**（扩散尾未测全），
    返回 n-1 = **不截断**（保留全部点）。缺了这一步，全段单调的数据会被截到
    "第一个低于 1e5 Hz 的点"（只剩十来个点），与条文"不要截断"直接矛盾。"""
    n = len(f)
    tail_start = n - 1
    for i in range(n - 2, -1, -1):          # 从低频往高频扩，遇到回升就停
        if zi[i + 1] <= zi[i]:
            tail_start = i
        else:
            break
    while tail_start < n - 1 and f[tail_start] >= fmax_search:
        tail_start += 1                     # §2 的搜索范围：截断点必须 < 1e5 Hz
    has_max = any(zi[i] > zi[i - 1] and zi[i] >= zi[i + 1] and f[i] < fmax_search
                  for i in range(1, n - 1))
    return tail_start if has_max else n - 1
```

> **为什么不能用"取最靠高频的谷 + 抖动容差"**：同一段数据可能既"在容差内"又"含一个弧"，两个分析者会得出相反结论。实测该做法会把窗口下沿定到弧 1 与弧 2 之间的谷，被多删的那一段含一个完整半圆，`R_pol_in_window` 被**系统性低估两位数百分比**，而 `R` 几乎不变。**只核对 `R`、或只看"残差合格"，完全发现不了这个错误** —— 必须靠 H1′。

**【硬门槛 H1′】截断不得删掉半个弧**

对被删掉的每一段（自截断点向低频一直到该圈 `f_min`）**逐圈**检查：

1. **唯一判据**：该段 `Z''` **必须单调不增**（对段内相邻点逐对检查 `Z''[j+1] ≤ Z''[j]`）。用 R2′ 定出的截断点天然满足本条（这是定义而非巧合），因此 H1′ 的实际作用是**事后复核**：对已去尾的文件、或对别人给的截断点，回头验一遍。
2. 若出现任何回升（`Z''[j+1] > Z''[j]`），说明截断点下方删掉了一个弧（段内出现"深→浅"或"深→浅→深"的回折）。**本条针对口径 A**（本圈 R2′ 删除段），处置是确定性的：改用 **R2′** 重定截断点并**整轮重跑** `01_` → `07_` 全部产物（重定会改变该圈 `i*`，必然终止）。口径 B 见第 3 条。
3. **两类"被删段"必须分开判，否则会与 H1.2 互锁成无限重跑**：
   - **口径 A = 本圈 R2′ 删除段**（自 `i*+1` 到该圈 `f_min`）：由定义保证单调不增，恒 PASS。这是第 1 条的原意。
   - **口径 B = 统一窗口合并删除段**（自 `f_min_common` 起向低频）＝实际被删掉的点。当某圈的 `i*` 因尾段抖动落到远低频时，口径 B 必然在该圈留下一处回升（它删得比 R2′ 更多）。此时若照第 2 条直接判 FAIL 并要求重跑，而重跑后 H1.2 仍取同一个 `f_min_common`，就会**永远 FAIL、永远重跑**。
   - 口径 B **不走"重跑"这条路**（重跑不会改变 `f_min_common`），改走下面的三步：
   - **第 1 步 · 弧判定（结构判据，决定性）**：在被删段内找出所有 **`Z''` 的局部极小点 `d`**（= 弧峰，`Z''` 最深处），对每个 `d` 取它两侧最近的**局部极大点**（= 谷）`v₁`（高频侧，没有就取段首点）、`v₂`（低频侧，没有就取段末点），算**收口比**
     `κ = max(|Z''(v₁)|, |Z''(v₂)|) / |Z''(d)|` —— 取两侧谷里**更深**的那个，即要求弧在**两侧都收口**。
     真半圆一定被两侧的浅谷夹住，故 `κ` 显著小于 1；扩散尾里的抖动两侧都是深点，`κ` 接近 1。
     **但 κ 只能抓『整个弧落在被删段内』的情形；公共窗口更常见的是『切在弧上』（弧只被削掉一部分，段内没有 `d`）。所以切弧判定必须同时用下面三条，任一条成立即判『公共窗口切掉了该圈的弧』**：
     - **① `κ`**：段内存在 `d` 且 `κ_min < 0.5`；
     - **② 峰数对比**：用 §7 判据分别数『本圈 R2′ 窗口』与『公共窗口』下的峰数 —— **窄窗峰数 < 宽窗峰数**（少了弧）；
     - **③ 窄窗 `γ_max` 位置**：窄窗的 `γ_max` 若落在**慢端 0.5 dec 以内或之外**（即 `τ(γ_max) ≥ τ(f_min_common)/10^0.5`，属慢端外推区），说明被切掉的极化被推到了窗口外。
     > 三条判据的取舍依据（实测，双弧批次）：只切尾段时窄窗 `γ_max` 距慢端 3.9–6.6 dec、峰数不变；切在弧上时窄窗峰数少 1 个、`γ_max` 落到慢端之外（−0.5 dec）、`ΔR_pol` 达 34–45 %。
     > 三个**不能用**的替代判据（都实测失败过）：① "回升幅度 ≤ 2 %\|Z''\|" —— 深尾里 `|Z''|` 有数 Ω，抖动占比很容易超过 2 %；② "两窗口 `R_pol_in_window` 差多少" —— 扩散尾本身携带可观极化，窗口一变就天然差两位数百分比（实测 20 % 量级），那是**代价**不是"被删弧"；③ "把连续上升段当回折" —— 从弧峰到谷本来就是连续上升，会把一段误判成几十处回折。
   - **第 2 步 · 判为『可能含被删弧』（①②③ 任一成立）时**：**必须**把该圈**移出跨样品对比**（单独按本圈 R2′ 窗口交付，并声明『不可与其它圈直接比较』），或把公共窗口收窄到该圈谷点；并用平行拟合量化代价（给出 ΔR / ΔL / ΔR_pol）。**不得**反复重跑同一条路径。
   - **第 3 步 · 三条都不成立 → 判『杂波 / 代价』，不重跑**：披露 `κ`（若有 `d`）、峰数与 `γ_max` 位置、几何；计入 H1.3 的代价清单；给出平行拟合的 ΔR / ΔL / ΔR_pol（**只切尾段时 `ΔR_pol` 出现两位数百分比属正常代价**：实测单弧批 22–24 %、双弧批 4–17 %，均判代价）。
   - **窗口不变性检查（最强止损）**：若该圈 `i*` 的歧义取值不影响 `max_i f_valley,i`（即 `f_min_common` 由别的圈决定），则公共窗口与全部交付数值都与该歧义无关 —— 此时**只需披露，不需重跑**，报告里要写明。
   - 口径 A、口径 B 的结论**都要**写进报告。
4. 报告必须给出每圈的：**全部谷候选**（频率与 `Z''`）、**R2′ 的 `i*` 与截断频率**、**被删段点数**与 **`Z''` 首值/末值**（段内非单调时还要给峰值）。
5. 中途改过截断口径，必须给出**新旧口径对照**（至少 `R`、`R_pol_in_window`、窗口点数）并声明**旧值作废**（§8.0.6 E2）。

**【硬门槛 H1】组内一致性 + 输入完整性**

1. 同一比较组内，所有文件**截断后的整条频率向量必须逐点相同**（不是只比 `f_min`）。
2. **组内不一致时的合规收敛路径**（不是停止交付）：取 `f_min_common = max_i f_valley,i`（各圈用 **R2′** 定出的谷点中**最靠高频**的那个；**max 是对频率取，不是对索引取** —— 写成"最大索引"会把整条扩散尾留在窗口内），全体统一到 `[f_min_common, f_max]`，缺失的低频点按 §1 第 5 条从同名完整源文件恢复。
3. **代价必须披露**：统一窗口会削掉部分样品自身的谷点（实测被舍弃的点里**大部分正是各圈自己的谷点**）。必须用**平行拟合**证明不影响结论：给出两窗口下的 ΔR、ΔL、ΔR_pol，并在报告里列出舍弃点数与其中谷点的个数。
4. 跨样品比较**必须先固定同一 λ**，再谈差异（见 §4.2 第 3 条）。

```python
def common_window(f, i_star):
    """H1.2：f_min_common = max_i f_valley,i（频率最大者）；返回公共窗口的**索引** j。
    f 递减（§1 第 4 条），故 j 随"频率最大"取到**最小**的那个截断索引。"""
    f_valley = [f[i] for i in i_star]                 # 各圈 R2′ 定出的谷点频率
    f_min_common = max(f_valley)                      # ← 关键：对频率取 max
    j = min((i for i, fv in zip(i_star, f_valley) if fv == f_min_common), default=min(i_star))
    return j, f_min_common
```

**自检**：`f_min_common` 一定等于各谷点里**最高**的那个频率；若算出来是最低的那个（或索引最大者），说明写反了 —— 那会把整条扩散尾留在窗口内，`R_pol_in_window` 虚高，且与"去除低频扩散尾 = 是"冲突。

**公共窗口是双向的（上沿也必须统一）**：下沿 `f_min_common = max_i f_valley,i`；**上沿** `f_max_common = min_i f_max_window,i` —— 当某圈因**整段高频污染**（§1 第 7 条）下移了自己的窗口上限时，全体必须一起下移到同一上沿，否则 H1.1 的"频率向量逐点相同"不成立。

- 下移量 ≤ 0.5 个十倍频 → **全体下移**（保可比性优先），披露舍弃的点数、频率范围与原因；
- 下移量 > 0.5 个十倍频 → **把该圈移出跨样品对比**（单独交付），**不要**拖累全体；
- 若被移出对比的圈达到或超过**半数** → **本批次不做跨样品对比**（各自按本圈窗口独立交付），并在报告开头写明原因（各圈的弧落在不同频段，统一窗口会切弧/削顶）。

**【硬门槛 H2】覆盖前备份**：改写任何原始数据文件前，先复制到 `_backup_<日期>\` 子目录；原始文件与 `_backup_` 一律**不改名、不覆盖**，去尾结果只能写进 `01_去尾后数据/`。

## 3. 模型与离散化

采用标准 DRT 模型（Tikhonov 正则化 + γ ≥ 0；**本协议不依赖任何第三方 DRT 软件**，格式与判据全部由本文件定义）：

```
Z(ω) = R + iωL + Σ_k γ_k · Δlnτ_k / (1 + iω τ_k)
```

即 `Z' = R + Σ γ_k Δlnτ_k /(1+(ωτ_k)²)`，`Z'' = ωL − Σ γ_k Δlnτ_k (ωτ_k)/(1+(ωτ_k)²)`。

- `R`：欧姆电阻（Ω）；`L`：串联电感（H），仅在用户要求或高频 `Z'' > 0` 时启用
- `γ_k ≥ 0`：弛豫时间分布（Ω），**非负是物理要求，必须强制**
- `Δlnτ_k = gradient(ln τ)_k`（对 ln τ 的梯形积分权重）

| 离散化 | 规则 |
|---|---|
| 定义 | `τ(f) = 1/(2πf)` |
| 范围 | `τ ∈ [τ(f_max)/3.162, τ(f_min)×3.162]`，即**两侧各外扩 0.5 个十倍频** |
| 点数 | `N = 400`（300–800 均可；结果必须对 `N` 不敏感，见 H5） |
| 分配 | `logspace` 均匀分布 |

**【硬门槛 H3】快端必须外扩**：`τ_min` 必须**小于** `τ(f_max)`。若 `τ_min > τ(f_max)`，DRT 没有基函数承载最快的那部分极化，质量被迫堆到 `R` 上 → `R` 被高估到 `min Z'` 之上（**违反 H4**）、高频 `Δ_Re` 系统性为正且越往高频越大，**此误差无法靠调 λ、FWHM 或权重消除**。
**但也别外扩过头**：`τ ≪ 1/ω_max` 的 γ 团块与串联 `R` 数学上不可区分（简并），外扩超过 ~1 个十倍频会让 `R` 不可靠。建议 0.5 dec，最多 1.0 dec。

### 3.2 是否包含串联电感 L —— 自动判定，用户无需指定

1. 计算 `maxZpp = max(Z'')`。
2. **`maxZpp > 0`（存在感性频点）→ 必须包含 L。** 严格理由：`γ ≥ 0` 时 DRT 核是纯容性的，`Im{Z} = ωL − Σ_k γ_k Δlnτ_k (ωτ_k)/(1+(ωτ_k)²) ≤ ωL`，不含 L 时 `Im{Z} ≤ 0` 对所有频率成立，**模型在数学上无法拟合任何 `Z'' > 0` 的点**。
3. **`maxZpp ≤ 0`（全段容性）→ 有 L / 无 L 各拟合一次**：两者都通过 §5 硬门槛时取**不含 L** 的简单模型；若不含 L 时 `max|Δ_Im| > 1 %`，保留 L。
4. 无论结论如何，**报告必须写明模型是否含 L 及 `L` 的数值**。
5. `L` 的物理含义：线缆 + 夹具 + 仪器高频响应的**集总等效**，**不具电化学意义**，不得当作样品参数写进讨论；样品真实的高频过程应体现在 DRT 快峰上（但需按 H10 先排除线缆污染）。
6. **同组内 `L` 必须大致恒定（夹具变更识别）**：`L` 是夹具/线缆的集总等效，**同一电池（或同一样品系列）在同一测量会话里应当基本不变**。若某圈的 `L` 偏离组内**中位数 > 2 倍**（或 `Z''(f_max)` 成倍变化），必须判为『**夹具/接线变更**』：
   - 该圈**不得**与其它圈做定量对比（`R_pol`、峰高、跨圈趋势），只能单独交付；
   - 报告里写明该圈的 `L`、组内中位数与偏离倍数，并给出"测量会话/夹具可能不同"的结论；
   - **不得**把 `L` 的跳变解释成样品或电池的变化。
   > 实测：同一次测量里若换了夹具/接线，`L` 可以差 3 倍以上，而且这些圈的顶部会**同时**出现连续多个 `Z'` 非单调点（§1 第 7 条的『整段排除』情形）—— 两者互为佐证，一起指向夹具，而不是样品。

> 实测方向（多批数据，唯一差别是有无 L）：含 L 时两条残差判据都在 1 % 以内；不含 L 时高频残差成数量级恶化（可达 10 % 量级），且 `R` 被顶到 `min Z'` 之上（**违反 H4**）。因此本类数据（10⁶–10² Hz，最高频 `Z'' > 0`）**必须含 L**。

**术语统一**：**最快十倍频** = `f ∈ [f_max/10, f_max]`（等价 `τ ∈ [τ(f_max), 10·τ(f_max)]`），H5′、H9、H10 一律指这一段；`γ_max` 除特别说明外指**全网格**最大值（H8 要求同时报窗口内最大值的比值）。

**【硬门槛 H5′】`R` 的简并区间必须披露**

顶频处谱线尚未进入欧姆平台时，`R`、`L` 与最快端 `γ` 团簇**三者简并**，只报单一 `R` 会给出**虚假精度**。触发条件（满足任一）：

- `min Z' − R > 0.02 × min Z'`（谱线在顶频还没走平）；
- 最快十倍频对 `R_pol_total` 的贡献 > 10 %；
- H5 的**外扩方向**差异 > 0.1 Ω。

触发后必须：

1. 做**固定 `L` 扫描**：用 `Z'' → Z'' − ωL₀` 配合**无 L 模型**等价实现（见附录 A 的 `fit_drt_noL`），记录各 `L₀` 下的 `R`、残差与 `γ(τ_min)/γ_max`。清单取
   **自适应清单** `L₀ ∈ {0.6, 0.7, 0.8, 0.9, 1.0, 1.1, 1.2, 1.3, 1.4} × L̂`（以主结果 `L̂` 为中心、**步长 0.1**）**∪** `{0.5, 2.0} × L̂`（括档，用来显示合格区边界）**∪** `{0, 50, 100, 150, 200, 250, 300, 500} nH`（历史清单，仅为跨批次可比）。
   报告中**分别**写"自适应清单合格解数"与"历史清单合格解数"；历史清单为 0 时说明它与本体系 `L` 量级不匹配（工具性空转），**不判 FAIL**，但必须披露。
   > **步长不许放粗**：合格区往往只覆盖 1–2 个格点。若清单写成粗格（如 `{0.5, 0.75, 1.0, 1.25, 1.5, 2.0} × L̂`），合格解可能只剩主结果一个，`R` 区间被压成**零点几 Ω**，而真值可达**数 Ω**（低估 3 个数量级）—— 这正是 H5′ 要防的"候选解集退化"。历史清单按 `L ≈ 0.2 µH` 体系设计，`L` 量级更大的体系上会 **0/8 合格**，只按历史清单做同样会退化。
   > **若自适应清单的合格解数 ≤ 1**（区间跨度 < 0.01 Ω）：这可能是**真实结论**（`L` 可定得很紧），但必须显式写明"候选解数 = N"、合格区边界（从哪个 `L₀` 开始超限、超的是哪条判据），**不得**静默给一个零点几 Ω 的区间。
2. 把 `R` 报成**区间**：候选解 = **同一模型、同一网格下 H7 三条残差判据全部合格**（`max|Δ_Re| ≤ 1 %`、`max|Δ_Im| ≤ 1 %`、`rms ≤ 0.1 Ω`）的全部解，取自 ① 主结果、② 固定 `L` 扫描（自适应 ∪ 历史）、③ H5 的**四个**网格配置（`N ∈ {400, 800}` × 外扩 `{0.5, 1.0} dec`，每个配置各自筛一遍）。区间 = 这些解的 `R` 的 min … max，并说明每个端点来自哪个配置。
   > **判据不许与 §4.1 混用**：§4.1 的 λ 验收是"残差 + 无快端伪峰"，H5′ 的候选只要**残差**合格。把快端伪峰条件也叠加进来，会把 `R` 区间从**数 Ω 压成零点几 Ω**（实测：合格区边缘的几个 `L₀` 残差合格、但快端比超 5 %，被这条混用规则一并剔除）。
3. 把该区间与 H11 的 λ 口径不确定度**并列写出并比较大小**；若某批数据两者相当或更小，照实写，不要套用"一定更大"。
   > 实测：H5′ 触发时该区间可比 H11 的 λ 口径**大一个数量级以上**（λ 口径常在零点几 Ω，简并口径可达数 Ω）—— **只报 λ 口径等于没报不确定度**。

## 4. 正则化与求解

```
min_x  ||A x − b||²  +  λ · ||D₂ γ / Δ^1.5||²        x = [γ(1..N), R, L]
```

- `A`：由 §3 模型构造的 `2n × (N+2)` 矩阵；`b = [Z'_1..Z'_n, Z''_1..Z''_n]`
- `D₂`：二阶差分算子（`[1, −2, 1]`）沿 τ 索引；`Δ = mean(diff(ln τ))`，除以 `Δ^1.5` 使 λ **与网格密度无关**，不同网格/样品之间 λ 才可比
- 求解前对 `A` 各列做**规范化（除以列范数）**，解出后再还原，否则条件数会把梯度类算法拖死
- 边界：`γ ≥ 0`；`R`、`L` 无约束；推荐 `scipy.optimize.lsq_linear(..., bounds=(lb, ub), method="trf")`
- 权重：**不加权**的复数最小二乘（实部与虚部合并成一个最小二乘问题，等权）

### 4.1 λ 的选取（写死流程，不用"最优原则"；**L 曲线拐点不可信**，理由见附录 B）

1. **取默认值 `λ = 1e-6`**（本协议全部实证数据适用）。
2. 检查两条验收条件：
   - **无快端伪峰**：`γ(τ_min) ≤ 5 % × γ_max`（`τ_max` 端不作要求，理由见 §6）。`γ_max` 指全网格最大值；若它落在慢端外推区（`τ > τ(f_min)`），必须**同时**给出"对窗口内 `γ_max`"的比值（与 H8 一致）。
   - **残差达标**：`max|Δ_Re| ≤ 1 %` 且 `max|Δ_Im| ≤ 1 %`。
3. 不通过则 λ 按 ×10 递增（1e-5, 1e-4, 1e-3 …）重试；**λ 不得小于 1e-8**（开始过拟合，DRT 出现振荡甚至负 γ）。
4. **若到 `λ = 1e-1` 仍不通过 —— 合规落法（不得继续调 λ，也不得改判据）**：
   1. 回到**协议默认 `λ = 1e-6`** 出主结果（递增循环本身会把 λ 推过 1e-1，必须显式回到 1e-6；参考实现见附录 A 的 `select_lambda`）；
   2. 把未满足的条件**映射到硬门槛号**并判 FAIL：条件 ① 对应 **H8**，条件 ② 对应 **H7**；两条都不满足则两条都判 FAIL、都写进报告开头的"未通过项"；
   3. 在 `_工作文件/_results.json` 记录 **`lam_certified = false`** 与全部尝试过的 `(λ, γ(τ_min)/γ_max, max|Δ_Re|, max|Δ_Im|)`，并在 `_gates.json` 同步一份（**不得静默**；正常路径也要写 `lam_certified = true`）；
   4. 报告写明"§4.1 验收在 `λ ∈ [1e-6, 1e-1]` 全区间不可满足"及其**原因**，特别要说明**残差超限是否只集中在个别频点**：若是，则与 λ 无关（先按 H7′ 查夹具污染），继续调 λ 是纯浪费；
   5. **与第 3 条的先后**：先按第 3 条试完网格（外扩到协议上限 1.0 dec、`N` 到 800）再落到本条；报告里两件事都要写。
   > 实测：当超限残差集中在顶 1–2 个被夹具污染的点（H7′）时，残差在整个 λ 区间几乎不动（**任何 λ 都改不动**）；另一些数据集则随 λ 增大而单调变差 —— 报告里必须写清属于哪一种。

**【硬门槛 H11】`R` 的不确定度必须报告**：用 λ = 1e-6 与 1e-7 各解一次，记 `ΔR = |R(1e-6) − R(1e-7)|`；`ΔR < 0.5 Ω` 可按单一数值报告，`ΔR ≥ 0.5 Ω` **必须**报告为区间 `R ∈ [min, max]`。原因是 `R` 与 `τ → 0` 端的 γ 团块存在数学简并，单次拟合无法唯一确定 `R`；跨样品对比时 ±0.5 Ω 的系统性差异足以掩盖真实趋势。

### 4.2 λ 的双口径与"不可跨数据集照搬"

1. **λ 不可跨数据集照搬**：罚项没有按数据幅度归一化，`|Z|` 越大等效正则化越弱，"上一批用 1e-6"不能直接搬到本批 —— 默认值 1e-6 **必须当场用 §4.1 那两条验收条件复核**。实测两批次的通过边界就不同（一批 1e-6 通过、1e-5 即失败；另一批 1e-6 通过、到 1e-4 才失败）。
2. **两个跨度都必须报**：① **字面口径** `|R(1e-6) − R(1e-7)|`（判 `R` 能否按单值报告）；② **全区间口径**：在**全部通过验收的 λ 区间**内（各批不同，须实测确定）记 `R`、`R_pol_in_window`、`γ_max` 的跨度。
3. **禁止把"跨样品差异"与"λ 敏感度"混算**：把各样品的 λ 敏感度当成样品间差异会得到**假跨度**（实测该假跨度可达真跨度的 3 倍以上）。
4. **报告口径**：`R_pol_in_window` 的 λ 系统不确定度可达 **10 % 量级**，`γ_max` 在同一区间内可变化**数倍** —— 因此**趋势可比，绝对值与峰高不可定量比较**。

## 5. 【硬门槛】物理校验（逐条通过才可交付）

| **H21** | 报告必报数值核对 | §8.0.7：每个样品的 `R_ohm` 与 `R_pol_in_window_ohm` **必须出现在报告中**且不得写错 —— 由 `scripts/DRT归档工具箱.py verify` 判定（缺失/写错 → FAIL）。**派生量与上下文常数不校验，不设人工复核清单** |

**H10 判据（同号段判据；披露/警告项，不阻断交付）**：若启用 L，检查原始 `Z''/ω` 在**最快十倍频**内是否近似常数。

1. 先看该频段内 `Z''` **是否变号**（标志必须报）。
2. **若变号**（数据在该频段由感性翻为容性）→ 判 **H10 不通过**，处置 = 在报告中警告"最上面 1–2 个点可能含线缆/夹具杂散电感" + 建议做**短路参考测量** + 按 H7 的剔点补救（上限顶 1–2 点）+ 量化第 4 条三件套，**然后照常交付**。**不要**用比值下结论 —— 比值会被零交叉点污染（实测出现过比值 > 10 而拟合残差仍 < 1 % 的情形）。
3. **若不变号** → 在**同号段**上算 `max\|Z''/ω\| / min\|Z''/ω\| > 2` 即 H10 不通过，处置同上。
4. 无论合格与否，**量化三件套**：剔除顶 1 点后的 `ΔR`、剔除顶 2 点后的 `ΔR` 与 `R_pol_in_window` 变化、最快十倍频对 `R_pol_total` 的贡献占比。
   > 实测方向：顶部 1–2 个点受夹具污染时，剔顶 1 点 `ΔR` 为零点几 Ω 量级、剔顶 2 点可达 1 Ω 量级且 `R_pol_in_window` 变化 10 % 以上；最快十倍频对总极化的贡献可达 20 % 量级。

> H1′ / H5′ / H7′ 为与原有编号并列的硬门槛（H1′ 可视作 H1 的配套条款）。
> 任何一条不通过：回到 §3/§4 调整，**不得带着不合格的结果进入 §8**；**H10 例外** —— 它是披露/警告项，按该行第 2–4 条处置（警告 + 剔点补救 + 量化三件套）后即可继续交付。H16–H21 不通过：回到脚本/归档流程重跑，**禁止手工补写文件名、元信息或布尔列**（手工补写正是那些错误进入交付物的方式）。若穷尽手段仍不通过，交付时必须在报告开头显著标出未通过项。
> **"回到 §3/§4 调整"必须留痕**：报告里写清试过哪些手段（网格外扩量、`N`、λ 区间、有/无 L、剔点）及各自后果，否则下一位读者无法判断"FAIL"是数据的性质还是分析者的疏忽。

## 6. 诊断：常见陷阱与对策

| 现象 | 对策 |
|---|---|
| `τ_min` 处尖峰 / `R` 偏大 + 高频 `Δ_Re` 为正 | 按 H3 外扩网格；再考虑降 λ |
| `τ_max` 处尖峰（`γ` 达最大值数倍） | **属外推**，形状不可解读；报 `R_pol` 只用窗口内部分 |
| DRT 剧烈振荡、出现负 γ | 增大 λ；并强制 γ ≥ 0 |
| 不同样品 `R_pol` 相差数倍 | 统一到**公共频率窗口**后重算 `R_pol`；跨样品比较先固定同一 λ |
| 最高几个点残差显著大于其余 | 先做 **H7′** 体检：**顶 1–2 孤立点** → 剔点（上限顶 1–2 点）；**连续 ≥ 3 点** → **整段排除高频段**（下移窗口上限，不是剔点）。两者都要建议**短路参考测量**；**不要**为此反复调 λ/网格 |
| 被删段 `Z''` 出现回升（非单调） | 按 **R2′** 重定截断点；用 **H1′** 复核；**整轮重跑 `01_`→`07_`** |
| H1′ 判 FAIL → 重跑 → 又 FAIL，来回循环 | 那是**口径 B**：按 §2 H1′ 第 3 条做**切弧三判据**（κ / 峰数对比 / 窄窗 γ_max 位置）；都不成立判代价，披露后交付（**不重跑**）；任一条成立判切弧，把该圈移出跨样品对比 |
| **统一窗口下某圈少了一个 DRT 峰** | 公共窗口切在该圈的弧上（H1′ 口径 B 判据②）：把该圈移出跨样品对比，或收窄公共窗口到该圈谷点 |
| **窄窗的 `γ_max` 落在窗口慢端之外** | 同上（判据③）：被切掉的极化被推到慢端外推区。**不要**把它当成真实的慢峰讨论（§6 『τ_max 处尖峰属外推』） |
| 全部 λ 都不通过 §4.1 验收 | 按 §4.1 第 4 条：留在默认 λ、判相关门槛 FAIL、记录 `lam_certified=false` 并披露原因 |
| `R` 随网格外扩量变化数 Ω | 按 **H5′** 做固定 `L` 扫描并把 `R` 报成区间；提高顶频或改低感夹具后重测 |
| **同一电池各圈的 `L` 成倍跳变** | 判为**夹具/接线变更**（§3.2 第 6 条）：该圈移出定量对比、单独交付；**不要**解释成样品/电池变化。若同时出现连续多个 `Z'` 非单调点，按 §1 第 7 条整段排除 |
| **某圈的谷点远低于其它圈，统一窗口会削掉它的一个弧** | 按 §2 H1′ 口径 B 算**收口比 κ**：`κ < 0.5` 判"可能含被删弧"→ 把该圈**移出跨样品对比**（或收窄公共窗口），**不要重跑**；`κ ≥ 0.5` 判代价，披露后交付 |
| **多弧数据的峰只识别出一个** | 检查截断点：若用了"取最靠高频的谷"会把后面的弧整段删掉（H1′ 口径 A 会 FAIL）；R2′ 应保留**最后一个谷以上全部点**，峰数应等于弧数 |
| **单弧数据却识别出 2–3 个峰** | 按 §7 用**突出度**过滤旁瓣；剩下那个紧贴窗口快端的峰按 **H8′** 判断是否为夹具污染（实测它只由顶 1–2 个频点支撑） |
| `R` 区间只有零点几 Ω、看不出简并 | 改用 **H5′ 的自适应清单**（以 `L̂` 为中心、步长 0.1）；实测该修正可把区间从零点几 Ω 恢复到数 Ω 量级 |
| H10 明明变号却报"通过" | 按 §5 H10 判据：先报变号标志，变号即 H10 不通过（**警告项，照常交付**；不要只看比值） |
| 两版报告 `R_pol_in_window` 差 20 % 以上 | 口径变更必须**整轮重跑**，并在报告中给出新旧对照与旧值作废声明（§8.0.6 E2） |
| 公共窗口落到最低频的谷点、扩散尾没删掉 | 按 §2 的 `common_window()` 取**频率最大**者；自检 `f_min_common` 必须等于各谷点里最高的那个频率 |
| 报告里的 `R` 与汇总表 `Info` 版本对不上 | 同步 `PROTOCOL` / `PROTOCOL_VERSION` 并重出汇总表 |
| 生成脚本报 `no field of name f_Hz`，或字段名显示为 `\ufefff_Hz` | 读取端一律显式 `utf-8-sig`（§8.0.4 H18 第 6 条、§8.0.6 A1） |
| csv 换行是 CRLF、与同批文件不一致 | 显式 `lineterminator="\n"`（§8.0.4 H18 第 7 条、§8.0.6 A3） |
| 校验器打印 PASS，但某列/某页显然不对 | 按 **H19** 逐页校验，禁止回退与 SKIP（§8.0.6 B1/B4） |
| 归档后才发现输入文件在拟合之后被改过 | 按 **H20** 核对 `(n, f_min, f_max, md5)`，不一致则重拟合（§8.0.6 E1） |
| 长任务跑到一半被杀、产物半成品 / 日志被判为二进制 | 把 stdout 重定向到日志文件；脚本自己以 UTF-8 增量写日志（§8.0.6 D3） |
| 中文文档/日志乱码、行数莫名变少 | 文本读改写只用编辑工具，二进制复制用 `Copy-Item` + SHA256（§8.0.6 D4） |
| `_cache_*.npz` 搬不动、报文件被占用 | 先释放句柄再搬运（§8.0.6 D1） |
| 报告里的数字越改越多、`verify` 的候选计数每次都变 | 报告只引用**稳定行**（`[H21] …缺失或写错: 0`、`RESULT: H21 PASS`），完整输出留在 `_工作文件/_log_verify.txt` |

**跨样品/跨圈对比的强制要求**：所有样品必须截断到同一频段，或在**公共窗口**上重新积分 `R_pol`；不同窗口下的 `R_pol` 不可直接比较。

## 7. 参数定义（报告口径）

- `R_pol_total = ∫ γ dlnτ`（全网格）——**不要用它做跨样品对比**
- `R_pol_in_window = ∫_{τ(f_max)}^{τ(f_min)} γ dlnτ`（仅测量窗口）——**跨样品对比用这个**
- `R_pol_outside = R_pol_total − R_pol_in_window`（外推部分，仅供说明）
- **`R` 的报告形式**：H11（λ 口径）合格即可按单值报；但只要 **H5′** 触发，**必须**同时给出区间与跨度来源。跨样品比较固定同一口径（同一 λ、同一窗口、同一网格外扩量）
- 峰值识别（**多弧必用突出度**）：`γ` 的局部极大点 `p` 必须**同时**满足
  ① `γ(p) > 10 % × γ_max`（高度门槛）；
  ② **突出度** `prominence(p) > 10 % × γ_max` —— 从 `p` 向两侧走，直到遇到比 `γ(p)` 更高的点，取两侧最低谷中**较高**者 `v`，`prominence(p) = γ(p) − v`。
  记录峰的 `τ`、`f = 1/(2πτ)`、`γ(p)` 与 `prominence`。
  > 只按高度会**过计数**：正则化会在两个真峰之间留下旁瓣，实测单弧数据的旁瓣高度可达 15–18 % `γ_max`，而突出度只有 5–10 %。峰清单带突出度，**峰数才等于弧数**（多弧数据尤其如此）。
  > **边缘峰**：突出度落在门槛附近（10–15 % `γ_max`）的峰必须在报告里标为"边缘"，**不计入弧数**，也不得直接当作一个独立电化学过程讨论。
- 残差：`Δ_Re = 100×(Z'_fit − Z'_exp)/|Z_exp|`，`Δ_Im` 同理

## 8. 输出要求

### 8.0 命名与目录分类（【硬门槛】H16 / H17 / H18）

> **本节解决的问题**：同一批数据交给不同 AI 窗口，拟合结果在理论上一致，文件名与目录结构却各不相同，导致结果无法自动对齐、下游脚本找不到文件。**唯一目的**：让"同一批原始数据"必然得到**同一套文件名 + 同一套目录结构**。因此命名**全部由原始数据文件名确定性导出**，**AI 不得自行起名**。

#### 8.0.1 记号（全部可自动计算）

| 记号 | 定义 | 例 |
|---|---|---|
| `S` | 原始数据文件名**去掉扩展名**，逐字符原样保留（空格、大小写、下划线不动） | `EIS batch-2 run 1` |
| `Sfull` | 原始数据文件名**含扩展名** —— 也就是 §8.4 汇总表的列名 | `EIS batch-2 run 1.txt` |
| `STEM` | **体系名** = 全体输入文件名去扩展名后的**最长公共前缀**，去掉结尾的空格与 `_` / `-` / `#`（常见序号分隔符），并去掉开头的 `EIS `（大小写不敏感） | `batch-2 run`（由 `EIS batch-2 run 1..4.txt` 导出）；`run-3_#1..16.txt` → `run-3` |
| `DATE` | 处理日期 | `2026-10-12` |

**STEM 必须验证为"真前缀"**：公共前缀规则只在**至少两个文件的去扩展名名不同、且前缀本身不等于其中任何一个文件名**时才有效。以下情形自动规则**无效**，`STEM` **必须由用户给出**（模板里的"体系名 STEM"一栏）并在报告中写明来源：
- 输入只有 **1 个文件**（最长公共前缀退化为整条文件名）；
- 全部输入文件名去扩展名后相同；
- 前缀等于其中某个文件名本身。
> **不得**把样品级后缀（序号、批次尾巴）当作体系名。实测：单文件批次若照旧规则自动导出，会得到 `EIS-DRT <单样品名>.xlsx` 与 `DRT拟合报告_<单样品名>.md` —— 文件名里混进了样品序号，违反 H17 的溯源语义。
- 这些导出结果**必须打印进报告**（§8.6），以便人工核对。

#### 8.0.2 【硬门槛 H17】样品级文件名必须溯源到原始数据文件名

1. 样品级文件名 = `S` + 下表**固定后缀**，且 `S` 必须与原始文件名**逐字符一致**。**禁止**改名、缩写、去空格、重新编号，或用 `cycle01` / `1` / `sample1` 这类**内部序号**代替 `S`。
2. 后缀表（**不得自创变体**）：

| 内容 | 文件名 | 出处 |
|---|---|---|
| 去尾后数据 | `<S>_trimmed.txt` | §2 |
| DRT 拟合结果（固定文本格式，见 §8.1） | `<S>_fitted_DRT.txt` | §8.1 |
| 残差表 | `<S>_residuals.csv` | §8.2 |
| 单样品图（若按样品出图） | `<S>_DRT.png`、`<S>_Nyquist.png`、`<S>_residuals.png` | §8.5 |

3. **截断频率不许写进文件名**——`<S>_trimmed.txt` 就是全部；截断频率这类信息写进 §8.3 的 `f_min_Hz` / `f_max_Hz` 与报告。
4. **批次级**文件名同样固定：

| 内容 | 文件名 |
|---|---|
| 逐样品汇总 | `DRT_batch_summary.csv` |
| 全体 DRT 汇总表 | `EIS-DRT <STEM>.xlsx`（**只有这一个名字**；禁止追加 `_trimmed`、`_all_cycles`、`_v1.1` 等尾巴） |
| 图 | `图1_DRT叠图_<STEM>.png`、`图2_Nyquist_<STEM>.png`、`图2b_Nyquist高频放大_<STEM>.png`、`图3_残差_<STEM>.png`、`图3b_残差叠图_<STEM>.png`、`图4_参数趋势_<STEM>.png` |
| 报告 | `DRT拟合报告_<STEM>.md`（圈号范围如"第 1–N 圈"写在**正文**，不进文件名） |

5. **结果根目录名** = `<STEM>_DRT_<DATE>`；**禁止** `DRT_batch`、`DRT_v1.1_2026-10-07` 这类与体系无关的名字。协议版本号只写在报告与 xlsx 的 `Info` 页，**不进任何文件名与目录名**。

#### 8.0.3 【硬门槛 H16】输出必须按内容分类到固定目录

结果根目录下**只允许**出现下列 9 个目录（外加可选的 `README.md`）。**任何结果文件与中间文件都不得直接放在根目录。**

```
<STEM>_DRT_<DATE>/
├─ 01_去尾后数据/            <S>_trimmed.txt
├─ 02_拟合结果_DRT格式/  <S>_fitted_DRT.txt
├─ 03_残差表/                <S>_residuals.csv
├─ 04_汇总表/                DRT_batch_summary.csv、EIS-DRT <STEM>.xlsx、各类核查/敏感性 csv
├─ 05_图/                    图1…图4、单样品图
├─ 06_脚本/                  本次实际运行的全部脚本（保证可复现）
├─ 07_报告/                  DRT拟合报告_<STEM>.md
├─ _工作文件/                _results.json、_log.txt、_cache_*.npz 等全部中间件
└─ _backup_<DATE>/           原始数据备份（§2 H2）；备份内**保持原文件名不变**
```

1. `01_`…`07_` 的**编号与目录名固定**：不得改名、不得合并、不得缺号；某类确实没有内容也必须**建空目录**（放一个 `.keep`），使不同 AI 的输出结构一一对应。
2. 需要新增类别时只能**顺序追加** `08_`、`09_`…，并在报告中写明。
3. 分组较多时（多个平行样等）可在 `01_` / `04_` 内**再开一层**子目录，但子目录名同样要溯源（用 `STEM` 或用户给的分组名），叶子文件名仍遵守 H17。
4. 中间件、缓存、日志一律进 `_工作文件/`。

#### 8.0.4 【硬门槛 H18】数值格式与列结构必须固定（跨 AI 逐字节可比）

1. 纯文本结果统一：数值 `%.12g`（≥ 12 位有效数字，满足 §8.1 的 ≥ 10 位）、UTF-8 **带 BOM**、换行统一 `\n`（Python 用 `open(..., newline="\n")`）；**禁止**同一批文件混用 CRLF/LF 或不同有效位数。
2. `*.csv` 一律 UTF-8 带 BOM、逗号分隔。
3. §8.3 的 `DRT_batch_summary.csv`：**列名与列序必须与 §8.3 完全一致，不得增删**；缺失值写 `NA`（不写 `nan`、不写空）。
4. 布尔列统一写 `YES` / `NO`（**不写** `True`/`False`/`1`/`0`）。
5. §8.3 的 `sample` 列 = **`Sfull`**（含扩展名，与 §8.4 列名一致）；自然排序用的序号放在单独的 `cycle_index` 列。**禁止**把 `1`、`cycle01` 之类内部序号写进 `sample`。
6. **编码必须成对**：写入端 `utf-8-sig`，**读取端也必须显式 `utf-8-sig`**。`np.genfromtxt(..., names=True)`、`csv.DictReader`、`open()` 若按默认 `utf-8` 解析，BOM 会成为第一列列名的一部分（实测 `'\ufefff_Hz'`），后果是生成脚本报 `ValueError: no field of name f_Hz`、校验器取不到测量窗口。
7. **换行符不能只靠 `newline=""`**：`csv.writer` 默认行终止符是 `\r\n`，要写 LF 必须显式 `lineterminator="\n"`。
8. 其它文本读取与自检脚本同样一律 `encoding="utf-8-sig"`；同一批文件**禁止**部分有 BOM、部分无 BOM。

#### 8.0.5 命名不合规的真实后果（为什么 H16/H17 是硬门槛）

同一批数据的两份 AI 输出实测：一份用了 `cycle01_trimmed_3.16to1e+06Hz.txt` 这类**内部序号 + 把截断频率写进文件名**的命名，另一份把汇总表追加了 `_all_cycles` 尾巴。后果不只是"名字不好看"：汇总脚本按 `<S>_fitted_DRT.txt` 反推列名，遇到 `cycle01_DRT.txt` **根本找不到源文件** —— 实测**整表所有列全部 SKIP，脚本仍打印 `H14 PASS`**，那份汇总表一列都没被校验过。**命名不合规会让硬门槛静默失效**；真正的防线是命名本身（H17），校验器判 FAIL 只是第二道防线。

#### 8.0.6 归档（整理）环节的防坑条款（H19 / H20 的落地）

> 拟合结果本身通常是对的，**坏在"打包"这一步，而且绝大多数不会自己报错**（症状是某列数字错、某条硬门槛静默失效、或交付物溯源信息失真）。实测已交付的 workbook 里，`DRT` 页全部通过 H14（`maxdiff = 0`），但按本节规则重跑后**仍报多项 FAIL**（布尔列写死、`Summary` 页 schema 不符、版本串过期）—— 坏的全在"包装"层。

| # | 条款 |
|---|---|
| A1 | 写 BOM 与读 BOM 必须成对：全部读取端显式 `utf-8-sig`（H18 第 6 条） |
| A3 | `csv.writer` 必须显式 `lineterminator="\n"`（H18 第 7 条） |
| B1 | 缺残差表 → 该列判 **FAIL**，不得回退、不得 SKIP（旧版会退化为"拿含外推边距的拟合网格当测量窗口"，使 H14 第 2/3 项静默失效） |
| B2 | `Summary` 按 §8.3 固定 schema 校验，布尔列必须**真算**并逐行回算比对 |
| B3 | 生成器与校验器各设**唯一**版本常量（`PROTOCOL` / `PROTOCOL_VERSION`），升版只改这一处；`Info.protocol` 与本版不一致判 FAIL |
| B4 | 缺源列 / 空列名 / 重复列名一律判 FAIL。**通用规则：任何断言必须能构造出一个反例使其为假，否则它只是装饰** |
| B5 | 窗口边界判据只允许定义一次（`BOUND_TOL = 1e-12`），生成器与校验器共用同一常量 |
| C1 | 同网格直取路径要求 `= 0`；**插值路径**容差 `1e-9 × max\|γ\|`，并必须在报告中注明"走了插值" |
| C2 | 校验器回算 `DRT` 页空白数并与 `Info` 比对 |
| D1 | 归档前先释放所有中间件句柄（`close()` / 重开进程），再统一搬运 |
| D2 | 路径写进 `.py` / 参数文件，不经 shell 字符串传递 |
| D3 | `PYTHONIOENCODING=utf-8`；脚本内 `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`；日志由脚本自己以 UTF-8 增量写 |
| D4 | **禁止**用 shell 处理中文文本：读改写只用编辑工具；二进制复制用 `Copy-Item` + SHA256 复核 |
| E1 | **H20（硬门槛）**：归档前逐文件比对"当前输入"与"拟合记录"的 `(n, f_min, f_max, md5)`，任一不一致必须**重拟合后再归档** |
| E2 | 参考实现**只保留一份权威副本**；各批次归档时**复制**该副本进 `06_脚本/` 并把 **md5 写进报告**；`06_脚本/` 只记录"实际跑过的那一版"，**禁止就地修改**。作业开始时先记下所用脚本的 md5；中途若脚本被改写，必须整轮重跑 |
| E3 | 报告自身写完后重算清单；`.keep` 只在**确实为空**的目录放 |
| F1 | 用 `%`-格式化生成报告时，正文里所有字面 `%` 一律写 `%%`；优先改用 f-string |
| F2 | 所有数值列必须显式格式化（`%.12g`）；禁止把对象直接交给写入器 |
| F3 | 一切 CSV 写入走 `csv.writer` / `csv.DictWriter`，**禁止手工拼接字符串** |
| F4 | 表格内所有竖线一律写 `\|`；交付前用脚本自检"**每行拆出的列数 == 表头列数**"。**并额外检查文件内不存在 NUL 字节**：`\|` 曾被误写成 NUL（本包 v1.12 有 7 处），渲染时文字断裂，而列数自检恰好测不出来 |

### 8.1 每个样品一个拟合结果文件（固定文本格式）

```
L,<数值>
R,<数值>
tau,gamma
<τ_1>,<γ_1>
...
<τ_N>,<γ_N>
```

文件名固定为 `<S>_fitted_DRT.txt`（§8.0.2 H17）。数值保留 ≥ 12 位有效数字（`%.12g`），UTF-8 带 BOM，`\n` 换行（§8.0.4 H18）。

### 8.2 每个样品一个残差表 CSV

文件名固定为 `<S>_residuals.csv`（§8.0.2 H17）。列（名字与顺序固定，不得增删）：

`f_Hz, Zre_exp, Zim_exp, Zre_fit, Zim_fit, dRe_percent, dIm_percent`

### 8.3 汇总表 `DRT_batch_summary.csv`

列（**名字与顺序固定，不得增删**，见 §8.0.4 H18）：

`sample, cycle_index, n_points, f_min_Hz, f_max_Hz, R_ohm, L_H, R_pol_total_ohm, R_pol_in_window_ohm, R_pol_outside_window_ohm, max_dRe_percent, max_dIm_percent, rms_percent, min_gamma, edge_fast_gamma, edge_slow_gamma, R_le_minZprime`

- `sample` = **原始数据文件名（含扩展名）**，与 §8.4 汇总表列名逐字符一致；**不得**填内部序号。`cycle_index` = 自然排序用序号（只用于排序，不用于命名）。
- `R_le_minZprime` 等布尔列统一 `YES` / `NO`；缺失值写 `NA`。
- **`rms_percent` 的定义**：`sqrt(mean([Δ_Re%, Δ_Im%]²))` —— 即**百分数残差的 RMS**（工具箱实现口径），**不是** `rms/|Z|`。而 H7 的判据 `rms ≤ 0.1 Ω` 用的是**复数残差的绝对量**（`sqrt(mean(|Z_fit − Z_exp|²))`，单位 Ω）。两者是不同的量，报告里必须写清用的是哪一个（两者**不可互相换算**：实测同一批数据上 `rms` 为 0.0X Ω 量级时 `rms_percent` 为 0.1X % 量级）。
- **生成方式**：由工具箱 `summary` 子命令**直接产出**，不要再为每个批次自写导出脚本。`summary --csv` 是另一个东西（§8.4 的**矩阵** csv），**不要**用它替代本表。

### 8.4 全体数据 DRT 汇总表（`EIS-DRT <体系名>.xlsx`）

**用途**：把所有数据集的 DRT 曲线汇到一张表，可直接导入 Origin / Excel 叠图。**文件名固定为 `EIS-DRT <STEM>.xlsx`**，不得追加任何修饰；体系名由 §8.0.1 导出，**不由 AI 自拟**。

- **第 1 行**：第 1 列固定写作 `tau`；其后每列一个数据集，**列名 = 该数据集的原始数据文件名**（含扩展名）
- **第 2 行起**：第 1 列 `τ / s`，其后各列为该数据集的 `γ / Ω`
- 列顺序按样品序号**自然排序**（1, 2, …, 10, 11, 12），不是字典序（`1, 10, 11, 2, …`）

**公共 τ 轴**——所有列必须落在同一根 τ 轴上：

1. 每个数据集的**有效窗口** = 其测量窗口 `[τ(f_max), τ(f_min)]`；网格外扩区属外推，**不进汇总表**。
2. 若全体数据集的 τ 网格完全相同（同频段、同 `margin`、同 `N`）→ **直接取用，不做插值**（首选，零误差）。
3. 否则 → 公共轴取全体有效窗口的 **并集** `[min_i τ(f_max,i), max_i τ(f_min,i)]`，点数按**最细的那个数据集的密度**确定（`N = round(并集跨度的十倍频数 × max_i(N_i/跨度_i))`）；各 γ 在其自身窗口内按 **ln τ 线性插值**并 `clamp(γ, 0, +∞)`。
4. 并集模式下必然出现空白单元格，语义必须严格：**不在其自身窗口内** → 留**空白**；**绝不填 0**（填 0 会在图上画出假的零线，比丢数据更危险）；也**不得**把网格外扩区（外推）的 γ 填进来充数。

**【硬门槛 H15】轴必须取并集，不得取交集**：并集之外的任何做法都会**不可逆地损失频段**。实测对照（3 个合成数据集，窗口分别为 100 Hz–1 MHz / 1 kHz–1 MHz / 10 kHz–1 MHz）：

| 轴模式 | τ 轴 | 100 Hz–1 MHz 那个数据集 |
|---|---|---|
| **并集（默认）** | 320 点，1.59×10⁻⁷ – 1.59×10⁻³ s | 320 点全部保留 ✅ |
| 交集 | **160 点，只到 1.57×10⁻⁵ s** | **10 Hz – 10 kHz 整段丢失** ❌ |

因此**默认 `--mode union`**。仅当确实需要一张无空白的完整矩阵做统计时才用 `--mode intersection`，并必须在报告中写明因取交集而损失了哪些频段。

**XLSX 工作表结构**（openpyxl 生成）：

**【硬门槛 H14】汇总表一致性校验**：生成后必须回读 xlsx 并逐列核对：

1. **有值单元格**必须落在该数据集自身窗口内，且 γ 与 `*_fitted_DRT.txt` 在同 τ 上的值一致。**同网格直取路径**（规则 2）要求**最大绝对差 = 0**；**插值路径**（规则 3）容差为 `1e-9 × max|γ|`，且**必须在报告中注明"走了插值"** —— 插值路径不可能逐位相等，把 `= 0` 写死会把浮点舍入误报成不一致。
2. **窗口内每一行都必须有值** —— 不允许把有数据的点漏成空白。
3. **窗口外必须为空白**，且空白**不得被写成 0**。
4. 表头第 1 格恰为 `tau`、τ 列严格单调递增、数据集列名**非空且不重复**（列名是回查源文件的唯一钥匙）。
5. **缺残差表或源文件缺失时不得回退、不得 SKIP**：窗口无法确定即判 FAIL。
6. 生成器与校验器的窗口边界判据**必须是同一常量**（`BOUND_TOL = 1e-12`）；两边不一致会让并集轴端点被误判成 `GAP`，产生整表假失败。
7. **校验必须覆盖 `Summary` 与 `Info` 两页**，不能只看 `DRT` 页 —— 见硬门槛 **H19** 与 §8.0.6 B2 / B3 / C2。

```python
import numpy as np
from scipy.optimize import lsq_linear

def load(path):
    rows = []
    for line in open(path, encoding="utf-8-sig", errors="ignore"):   # BOM 容错
        p = line.replace(",", "\t").split()
        if len(p) >= 3:
            try: rows.append([float(x) for x in p[:3]])
            except ValueError: pass
    a = np.array(rows); return a[:, 0], a[:, 1], a[:, 2]

def fit_drt(f, Zr, Zi, lam=1e-6, N=400, margin=3.1623):
    w = 2*np.pi*f; za = np.abs(Zr + 1j*Zi); n = len(f)
    T1, T2 = 1/(2*np.pi*f.max()), 1/(2*np.pi*f.min())
    tau = np.logspace(np.log10(T1/margin), np.log10(T2*margin), N)
    dln = np.gradient(np.log(tau)); wt = np.outer(w, tau); K = 1.0/(1.0 + wt**2)
    A = np.zeros((2*n, N+2)); b = np.zeros(2*n)
    A[0::2, :N] = dln[None, :]*K                      # Re
    A[1::2, :N] = -dln[None, :]*K*wt                  # Im
    A[0::2, N] = 1.0                                  # R
    A[1::2, N+1] = w                                  # L
    b[0::2] = Zr; b[1::2] = Zi
    dx = np.mean(np.diff(np.log(tau)))
    D = np.zeros((N, N+2))
    for i in range(N-2): D[i, i:i+3] = [1., -2., 1.]
    D = D/dx**1.5                                     # 与网格无关的曲率罚项
    Aa = np.vstack([A, np.sqrt(lam)*D]); ba = np.concatenate([b, np.zeros(N)])
    sc = np.linalg.norm(Aa, axis=0); sc[sc == 0] = 1.0        # 列规范化
    lb = np.concatenate([np.zeros(N), [-np.inf, -np.inf]]); ub = np.full(N+2, np.inf)
    s = lsq_linear(Aa/sc, ba, bounds=(lb/sc, ub/sc), method="trf", tol=1e-13, max_iter=5000)
    x = s.x/sc; Zf = A@x; g = x[:N]
    dRe = (Zf[0::2]-Zr)/za*100; dIm = (Zf[1::2]-Zi)/za*100
    win = (tau >= T1) & (tau <= T2)
    return dict(tau=tau, gam=g, R=x[N], L=x[N+1],
                Zfit=Zf[0::2]+1j*Zf[1::2], dRe=dRe, dIm=dIm,
                Rpol=np.sum(g*dln), Rpol_win=np.sum(g[win]*dln[win]),
                rms=np.sqrt(np.mean((Zf-b)**2)),
                ok_R=bool(x[N] <= Zr.min()), ok_g=bool(g.min() >= 0),
                edge_fast=g[0], edge_slow=g[-1])
```

**λ 的确定性选取流程**（§4.1；把"无合格 λ"的落法写进代码，避免循环越过 1e-1 把主结果算在 λ=1.0 上）：

```python
def passes(r):
    return (r["edge_fast"] <= 0.05*r["gam"].max()
            and max(abs(r["dRe"]).max(), abs(r["dIm"]).max()) <= 1.0)

def select_lambda(f, Zr, Zi, model=fit_drt, lam0=1e-6, lam_max=1e-1):
    """§4.1：从 1e-6 起逐级 ×10；到 1e-1 仍不通过则按第 4 条留在默认 λ=1e-6，
    并把 lam_certified 置 False（**不得**继续调 λ，也不得改判据）。"""
    lam, tries = lam0, []
    while lam <= lam_max * (1 + 1e-12):
        r = model(f, Zr, Zi, lam=lam)
        tries.append(dict(lam=lam, edge_ratio=r["edge_fast"]/r["gam"].max(),
                          max_dRe=abs(r["dRe"]).max(), max_dIm=abs(r["dIm"]).max(),
                          R=r["R"], R_pol_win=r["Rpol_win"]))
        if passes(r):
            return lam, r, tries, True
        lam *= 10
    r = model(f, Zr, Zi, lam=lam0)              # §4.1 第 4 条：留在协议默认值
    return lam0, r, tries, False

lam, r_main, lam_tries, lam_certified = select_lambda(f, Zr, Zi)   # 主结果
if not lam_certified:                                              # 必须留痕、必须披露
    print("WARN §4.1 验收在 λ∈[1e-6,1e-1] 全区间不可满足；主结果用 λ=1e-6；"
          "试过的 (λ, 快端比, 残差) =", lam_tries)
```
